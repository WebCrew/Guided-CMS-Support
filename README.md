Official public support, documentation and community hub for **Guided CMS** — a theme-first content management system for static HTML websites.

## Where should I post?

Use **Discussions** for usage questions, ideas and general conversations. Use **Issues** for reproducible bugs, documentation problems and focused feature requests. Please search existing posts first.

## Before reporting a bug

Include the Guided CMS version, PHP version, browser, hosting environment and reproducible steps. Describe the HTML theme structure without redistributing a commercial theme.

> Never post passwords, FTP/SSH or SMTP credentials, personal data, private website files, licence keys, Envato purchase codes or unredacted logs.

Please read [SUPPORT.md](SUPPORT.md), [SECURITY.md](SECURITY.md) and [CONTRIBUTING.md](CONTRIBUTING.md) before contributing.
