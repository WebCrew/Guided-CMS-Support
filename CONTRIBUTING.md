# Contributing

Thank you for helping improve Guided CMS.

## Good contributions

- reproducible bug reports
- corrections and clarifications for public documentation
- focused feature proposals with a clear user problem
- sanitized HTML structure examples that can be shared legally
- respectful answers in Discussions

## Before contributing

1. Search existing Issues and Discussions.
2. Choose the appropriate Issue form.
3. Remove credentials, personal data and private URLs.
4. Do not upload commercial themes, customer packages or Envato purchase codes.
5. Keep one report focused on one problem.

Pull requests are limited to invited collaborators. Documentation suggestions from customers can be submitted through the documentation Issue form.

By participating, you agree to follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
