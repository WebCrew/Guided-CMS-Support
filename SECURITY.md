# Security policy

## Reporting a vulnerability

Please **do not open a public Issue or Discussion** for a suspected security vulnerability.

Send a private report to **palareas@gmail.com** with:

- affected Guided CMS version
- clear description and impact
- safe reproduction steps
- relevant sanitized evidence
- whether the issue is already public

Do not include live credentials, customer data or third-party private files. If sensitive material is required, ask for a secure transfer method first.

We will acknowledge the report, assess its scope and coordinate disclosure after a fix or mitigation is available. Please avoid public disclosure while the report is being investigated.

## Supported versions

Supported release lines will be documented here when Guided CMS reaches its first public release.
