# Guided CMS support

## Public support channels

- Use [Discussions](https://github.com/WebCrew/Guided-CMS-Support/discussions) for questions, setup guidance and community knowledge.
- Use [Issues](https://github.com/WebCrew/Guided-CMS-Support/issues) for reproducible defects, documentation errors and focused feature requests.

## Information that helps

When reporting a technical problem, include:

- Guided CMS version
- PHP version
- browser and operating system
- hosting environment
- relevant page type and HTML theme structure
- exact reproduction steps
- expected and actual result
- a minimal, sanitized log excerpt when necessary

Do not upload or redistribute a commercial HTML theme. A reduced HTML example that reproduces the structure is preferable.

## Keep private data private

Never publish passwords, FTP/SSH details, SMTP credentials, API keys, licence keys, Envato purchase codes, private URLs, personal data, database exports, full server logs or private website archives.

Public GitHub posts are not an appropriate channel for purchase verification or account-specific information.

## Languages

Support can be requested in English or German. French interface feedback is welcome.
